## 📊 Excel Reports

Contains **56 Excel files** (`01.xlsx` → `900.xlsx`) sorted in ascending numerical order.  
Each file represents an individual patient lab report.

---

## 🩸 Hematology Report Images

Contains **10 images** (`Hematology_Report_01.jpeg` → `Hematology_Report_10.jpeg`).

Reports include tests such as:
- Haemoglobin %
- Total WBC Count
- Differential Count (Polymorphs, Lymphocytes, Eosinophils, Monocytes, Basophils)
- R.B.C. Count
- Platelets Count
- Bleeding Time / Clotting Time
- E.S.R. (Westergren)
- RBS

---

## 🧪 Biochemistry Report Images

Contains **12 images** (`Biochemistry_Report_01.jpeg` → `Biochemistry_Report_12.jpeg`).

Reports include tests such as:
- Glucose (RBS / FBS / PPBS)
- Urea
- Sr. Creatinine
- Aspartate Transaminase (SGOT)
- Alanine Transaminase (SGPT)
- Lipid Profile (Triglycerides, Total Cholesterol, HDL, LDL, VLDL)
- CRP Test
- HbA1c
